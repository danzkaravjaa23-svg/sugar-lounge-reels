# Зураг авах карт — ажилтнуудад (iPhone)

Апп бичлэгийг засаж чадна, харин муу авсан бичлэгийг сайн болгож чадахгүй.
Энэ 1 хуудсыг бар/KTV-ийн ажилтнуудад хэвлэж өгнө.

## iPhone-ы тохиргоо (нэг удаа)

Settings → Camera → Record Video:

| Тохиргоо | Утга | Яагаад |
|---|---|---|
| **HDR Video** | **OFF** | iPhone-ы HDR (Dolby Vision) бичлэг аппд цайвар, бүдэг харагдана |
| **Auto FPS** | **OFF** | Харанхуйд iPhone өөрөө 24fps болгодог — Instagram 30fps шаарддаг |
| Enhanced Stabilization | ON | Гараар авахад чичирхийлэл багасна |
| Action mode | OFF | Дотор харанхуйд шуугиантай болгоно |
| Нягтрал | **4K · 30fps** | Үндсэн. Slow-motion хүсвэл 1080p · 60fps |

Авахаасаа өмнө дэлгэц дээр **удаан дарж** (AE/AF LOCK) гэрэл, фокусаа түгжинэ —
неон гэрэл солигдоход зураг анивчихгүй.

## Юу авах вэ (reel бүрт 6–8 клип, тус бүр 4–8 секунд)

1. **Hero** — хамгийн амьд агшин: коктейль цутгах, гэрэл асах, хүмүүс дуулах. Энэ эхэнд орно.
2. **Walk** — орох хаалганаас бар → KTV коридор хүртэл нэг тасралтгүй алхалт (удаан, тогтвортой).
3. **Pour / shaker** — гар, мөс, шингэн ойрхон.
4. **Garnish** — чидун, хальс, утаа.
5. **KTV** — найзууд дуулж буй, дэлгэц, неон.
6. **Хүн** — ажилтан инээмсэглэж, коктейль барьж буй (заавал нэг клип хүний царайтай).
7. **Хоол** — ширээний spread, гол хоол.
8. **Wide** — бүтэн танхим, зочид, оргил үед.

## Дүрэм

- **Босоо** (9:16) л авна. Хэвтээ бичлэг хажуугаа тайруулна.
- Хүнгүй reel сул ажилладаг — Sugar-ийн 133K, 70K үзэлттэй reel-үүд бүгд хүнтэй, хошин.
- Коктейлийн ойрхон зураг 1080p·120fps-ээр авч болно, гэхдээ **шилний ард жижиг LED гэрэл** тавь —
  танхимын гэрэл 120fps дээр анивчдаг (50Hz цахилгаан).
- Бусдын бичлэг, TikTok/CapCut ватермарктай бичлэг **хэзээ ч** ашиглахгүй — Instagram үзэлтийг нь хаадаг.
- Том файл (4K, 30с+) 10-аас олон бол апп удааширна — клип бүр 4–8с байхад хангалттай.
